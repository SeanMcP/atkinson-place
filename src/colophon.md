This website was built using [Eleventy](https://www.11ty.dev/), a static site generator.

The main font is [Atkinson Hyperlegible](https://www.brailleinstitute.org/freefont/), a typeface designed by the Braille Institute to increase legibility for low-vision readers. In addition to being well-designed, the name was a perfect fit for this website.

Images are taken by residents of Atkinson Place and are used with permission. If you would like to contribute a photo, please email [the webmaster](mailto:sean@seanmcp.com).

The favicon was generated using [Favpie by PixelPoint](https://github.com/pixel-point/favpie).
